# Covenant-Studios
## Tooling

- Claude plugins (auto-enabled via `.claude/settings.json`): superpowers, caveman, claude-security
- Skills in `.claude/skills/`: OmniRoute skills (need the `omniroute` CLI: `npm i -g omniroute`)
- Commands in `.claude/commands/`: from rse/claude-code-setup (MIT)
- npm: `gsap`, `lenis`
- React Bits components: add one at a time, e.g. `npx shadcn@latest add https://reactbits.dev/r/SplitText-TS-TW`
