# Covenant Studios

## Creative references (always consult)

Before designing or building anything creative (graphics, motion graphics,
videos, websites, landing pages, brand work, UI), look at these sites for
inspiration and as the quality bar:

- https://savee.com/ : curated visual inspiration (graphic design, art direction, photography)
- https://landdding.com/c/agency : landing page gallery, agency category (layouts, hero sections, typography)
- https://www.motionin.design/ : motion design inspiration (animation, transitions, motion graphics)

How to use them:
- Browse them (WebFetch, or Playwright/Chromium if the page needs JS) at the start of creative work.
- Pull concrete cues: layout, type pairing, color, spacing, motion timing, interaction patterns.
- Draw from them; do not copy any single piece one-to-one.
- If a site can't be reached, say so and continue from these principles: bold editorial type,
  generous whitespace, strong grid, restrained palette, purposeful smooth motion.

## Tooling for creative work

- Motion/animation: `gsap`, smooth scroll: `lenis` (both in package.json)
- Video from HTML: hyperframes plugin (`/hyperframes:hyperframes`)
- UI components: React Bits (https://reactbits.dev), added per component
